# v109: complete evidence receives the available response capacity

Development experiment after v102 Gold was opened. Private v104 acceptance stays
hidden. Same200 questions, same64 physical lines/4 excerpts/12000 canonical JSON
characters, same identity and all-facet visible-evidence gate. No ranking, model,
query expansion, source identity, eligible supporting owner or language changes.

Three caller-level regressions failed before implementation: a class member lost
its declaration although its complete46 lines fit; a file response omitted a
function contract to quote an unrelated license header; a large class member used
only37 of64 available lines. Two file/module subcases failed independently.

EvidenceCardBuilder owns literal quotation, source deduplication and the shared
response budget. Class/symbol declaration and existing ranked supporting owners
retain their identity/order. For each of the existing two selected owners, quote
all exclusively owned ranges if they fit. Otherwise keep its declaration when
capacity allows, then use the remaining line capacity for its query-conditioned
implementation window. A file/module no longer reserves12 lines for a module
header regardless of relevance. Short symbol definitions retain v105 behavior.

The v105 large-symbol test now requires a window of AT LEAST36 lines rather than
EXACTLY36; source ownership,64-line ceiling and truthful truncation assertions are
unchanged. The new public test separately requires all64 lines to be useful owned
source for a large class member. This changes an incidental fixed quota, not an
acceptance threshold. No test or case was removed or skipped.

First-owner priority can omit complementary second-owner evidence. This is an
explicit hypothesis/control, not an adopted default or proof of improvement.
