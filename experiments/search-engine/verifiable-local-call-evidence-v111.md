# v111: a proven local callee can support the returned piece

Development-only context experiment; no private v104 case is read. Same64lines,
4excerpts and12000 canonical JSON chars, same200 queries, ranking, model/source
inputs, all-facet rubric and correct-piece+visible-evidence gate. No threshold or
reference changes. v109 independent review and68M FP32 control remain separate.

LocalCallEvidence owns the projection from existing structural TARGET facts to
canonical source owners. It lowers ONE complete source file, links lexical
declarations with the existing core linker, then retains only compact same-file
call edges and discards the full IR. Only unique TARGET without MAY_TARGET is
eligible, and only for tested Python/JS/TS language families. Both callable
owners must map uniquely by name AND physical source extent to the catalog.
The invocation must belong entirely to the caller's exclusive owned source.
Unknown targets, imports, external files, self recursion and ambiguous duplicate
owners supply no edge. This does not claim runtime dispatch, execution, purity,
transitive effects, or absence. Java qualified static calls remain unsupported.

Enrichment runs AFTER ranking for the single returned answer, not for every
candidate. It never changes the result identity or order. It appends direct
callees only when their complete invocation is already visible, preferring
source overlap with the public expanded query within the unchanged spare budget.
No facets/Gold enter selection. Original cards/pools are not mutated. Existing
response lines stay; no dependency receives a separate hidden context budget.
An excerpt's dependency metadata names its canonical caller and exact call span;
it does not manufacture source text or establish behavior by itself.

Validation fails closed unless an explicit resolver from the SAME source catalog
independently confirms the edge and visible invocation. Same-file provenance,
hashes, exact literal source, canonical owners and all response limits still
apply. A new helper excerpt cannot authorize another helper recursively. Hashing
the current source also invalidates cached resolutions after source changes.

Seven caller-level tests cover correct primary identity plus helper evidence,
parameter shadowing, a misleading same-name member in another class, fabricated
callee, hidden invocation, stale cached source, foreign resolver, and exhausted
excerpt capacity. No unchanged-line transitions are silently adjudicated.

Freeze helpers and rerun all200 through the prepared CPU pipeline to measure
actual dependency parse/cache cost, answer serialization and peak RSS. Add source
and budget authentication, compare all candidate orders, then blind-review every
byte-distinct response before reporting joint utility. Reranker precision trials
on old fixed cards do not constitute measurements of this new evidence format.
