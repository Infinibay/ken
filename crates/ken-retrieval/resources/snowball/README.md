# Pinned native English stemming

Snowball3.0.1, commit `e4b3efb449ccb994d39230eb6e8440d267471f4a`, BSD-3-Clause. `provenance.json` pins the compiler inputs, generated algorithm, original installed dependency and integrated Rust files. The official generator's Python output with filename `english_stemmer.py` is byte-for-byte identical to the original; both Python runtime files also match official source bytes. Python is used only as a migration reference.

To reproduce: verify upstream inputs, run the recorded `make` and generator commands, copy the raw Rust algorithm as `english.rs` and upstream `snowball_env.rs`/`among.rs` as `runtime.rs`/`among.rs`, then apply `integration.patch` with `patch -p1`. The patch updates module paths/names, removes generated warning suppressions and unused runtime operations, expresses single-pass labels as blocks, and applies checked lint simplifications. The wrapper `mod.rs` is repository-owned. The application needs neither a compiler nor Python.

The UTF-8 bridge in `stemming.rs` preserves isolated Python surrogate code points. English's replacement strings are ASCII; all deletion regions are ASCII possessives/suffixes or one ASCII letter selected by the double-letter table. It cannot delete or duplicate a non-ASCII marker. Region marks and character hops preserve character order under UTF-8 byte offsets. The bridge maps each surrogate to one non-vowel private-use scalar, records real occurrences of that scalar too, and restores them in encounter order. It checks marker conservation before returning. Differential cases cover the real marker, isolated surrogates, collisions, combining characters, emoji, all suffix groups, and128/129-codepoint cache boundaries.

Default English reuse is one shared cache of at most32768words. Explicit replacement providers each own their bounded cache. Computation occurs outside the cache mutex; each miss owns its Snowball buffer. Long words bypass retained state. Native tests exercise the complete original32769-word eviction/call sequence, fresh returned values, provider replacement, eight simultaneous misses and200 concurrent word groups. Full migration acceptance remains in the M4c1 plan.
