# Original transformer reference and native feasibility

This artifact freezes33 original profiles and432 requests from the immutable Python source in isolated locked environments. Torch2.9.0/macOS and2.9.0+cpu/Linux use ST5.6.1, Transformers4.57.6, NumPy2.4.4 and Tokenizers0.22.2; macOS MLX uses0.32.3 andMLX-LM0.28.4. INDEX authenticates bounded compressed records and the complete source-fixed inventory. The original1066-file guard passed.

Numerical preflight executes actual registered weights through standalone Rust programs outside the checkout. CPU is exercised on both platforms, MPS/MLX on actual Apple hardware. Linux traces contain the native executable only and audited native/system libraries; macOS library-load traces do not constitute kernel child-exec audits. Normalized-vector tolerance1e-6 and raw-score tolerance1e-5 were fixed before native execution. Linux dependency selection deliberately uses two observed encoder feeds per model/dtype and one judge projection feed per dtype; full production-adapter coverage remains mandatory.

Original empty judge documents load/check budget and then raise the pinned tokenizer's IndexError. A budget below16 instead raises ValueError first; on MPS this invokes the original CPU/F32 retry and permanently changes later execution. Captures record each attempt. Error cases occur last so all valid numerical cases retain actual MPS coverage. CPU retry converts already-loaded weights, retaining prior dtype rounding. Controlled lifecycle observations are policy tests, not hardware OOM or model inference evidence. The original CPU nonfinite-output gap is recorded; the approved native M2 contract rejects invalid vectors.

INDEX also retains21 complete instrumented repeat captures, checked byte-for-byte for inputs, outputs and state, and12 older macOS ST captures as explicit vector-repeat-only diagnostics. The older observer recorded no model feeds; those files cannot pass original capture validation and are never treated as complete token/feed evidence. Their numerical outputs repeat every macOS ST profile exactly. All33 canonical captures retain genuine observed feeds.

Before product model execution, INDEX freezes each profile deadline as max(60s,ceil(3*(original preparation plus sum of public call times))). This reserves protocol/verification overhead using original measurements alone; acquisition remains outside the deadline and the legacy600s gate remains unchanged. The already fixed vector1e-6/raw-score1e-5 tolerances are retained. These deadlines apply to production profile processes; standalone feasibility traces keep their original budgets.

Preflight sources and reproducers are research evidence, not installed application backends. Model/module lifetime, public text/token/prompt/device APIs, complete regression/resource/corruption tests, packaging and the remaining migration stages are still required. `model_inference_accepted` remains false; this artifact does not accept M2 or the complete migration. Original sources and data are retained. Official NumPy2.4.4 sort sources and license preserve the exact unstable ST character-length order; MLX keeps its separate stable token-length order.
