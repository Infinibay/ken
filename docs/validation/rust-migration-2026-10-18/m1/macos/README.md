# Recibos macOS M1

`summary.json` identifica los 16 gates ejecutados, fuentes, comandos y hashes.
`benchmark.json` conserva las 180 muestras completas y la preparación separada.
Los logs crudos y JUnit identificados por el manifiesto se conservan sin alterar
bajo `.ken/rust-migration/m0-m1/validation/` en el checkout de la validación.
El contraste público completo está en `../parity.json`.

Este recibo acredita aceptación local; la matriz requiere también Linux comparable.
