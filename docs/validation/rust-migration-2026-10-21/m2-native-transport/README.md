# Native public artifact transport

Both macOS and Linux executed the current release Rust acquisition consumer outside the checkout with a sentinel PATH, no Python runtime, invalid ambient proxy values and a fake HF token. The public request downloaded only the pinned BAAI/bge-m3 config.json:687bytes, SHA25626159e7ad065073448460117eb24b7a4572f6f4e78eadff65dc0a11c052449fa. The actual file is retained in each platform cache. A second process resolved it offline with a transport that refuses any network invocation; its observed transport call count was zero. Linux additionally audited execve, execveat and connect: only the initial native exec occurred and the offline trace contains no connect call.

Each summary records exact production source hashes, binary hash, public URL, declaration, commands and actual outputs. Each capture.py is the controller version actually used on its platform: the earlier Mac controller records a false both_exec_syscalls_observed field, while the Linux version explicitly names the audited syscalls. No Mac syscall-tracing claim is made. The loader/dependency logs contain no libpython or libtorch_python.

The six private real-server tests cover chunked streaming and exact anonymous GET paths,404/500, bad Content-Length/chunking, excess bytes, encoded bodies, redirect limits, HTTPS-only operation, real inactivity and total timeouts. The private test endpoint cannot be configured through the public constructor. One public integration test rejects invalid immutable requests before connecting; all eight cache publication/ownership tests and the compiled producer inventory also passed. Logs are retained, including Clippy with warnings denied. TLS uses only the already-locked ureq3.4.2/rustls dependencies; no package version changed.

ureq recv_body is a total duration rather than an inactivity duration. A small adapter on its pinned transport interface limits individual read waits to60seconds, keeping shorter global deadlines. The production global limit is3600seconds, connection/DNS limits15seconds, redirects10, and the cache streams64KiB blocks with an exact-size-plus-one bound. Active downloads can exceed one inactivity interval; continuously active reads still hit the global deadline. Automatic content decoding is prevented by rejecting non-identity encoding before consuming the body.

This proves acquisition and offline reuse of this small registered public artifact. It does not claim new neural inference, complete model-factory integration, hosted CI or M2/full-application acceptance. The original sources remain intact.
