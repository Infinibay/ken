## Purpose and responsibility boundary

Rank already-selected source owners using the original measured source features and registered numeric forests, with reproducible explanations. M4c1 implements numeric forest execution/identity, English stemming, term alignment/coverage, owner/contextual feature projection, EvidenceReranker, RankingTrace and registered forest loading. M4c2 retains source catalogs, requested-piece selection/features, physical freshness, bounded evidence/cards/presentation. M4d retains prepared production channels/runtimes (including mapped source-view pools and neural adapters), actual public CLI/MCP search and quality/resource acceptance. M5–M8 remain required. No capability is removed or called migrated by this library slice.

Concepts: `Matrix<T>` owns immutable rectangular numeric values and dimensions; `NumericRanker` owns validated named trees, canonical model identity, ordered prediction and pair explanations; `WordEncoder` supplies query/term vectors through one registered encoder owner; `EnglishStems` owns the exact English algorithm and provider-bound bounded reuse; `TermAlignment` summarizes each query term's best document match; `TermCoverage` owns its six measured summaries; `FeatureMatrix` binds ordered names to numeric rows; `OwnerFeatures` projects full canonical descriptions and candidate signals into the frozen schema; `EvidenceReranker` coordinates those components and stable owner order; `RankingTrace` retains one immutable request-local observation; `ProductionRankModels` verifies and lazily opens the two registered forests.

Representative use:

```rust
let descriptions = owner_descriptions(conn, &candidates)?;
let word_model = ManagedWordEncoder::new(prepared_encoder, word_spec);
let ranker = EvidenceReranker::new(native_model, word_model, EnglishStems::shared(), expansion)?;
ranker.validate(&profile.evidence.as_ref().unwrap())?;
let matches = ranker.rank(&request, &candidates, &descriptions, expanded.as_ref(), evidence_version, trace.as_mut())?;
```

## Binding contracts

Reuse Rust1.95, the accepted crate/model/storage/text owners, Unicode15 and NumPy2.4.4/Python3.12.9 reference. Retain source extractor8/parser10, code-lexical-v1 passage256 and representation3. Source descriptions remain version1. Models use schema1,1–512 distinct nonempty feature names,1–4096 trees and maximum tree depth64. Predictions preserve `<=` splits, input shape/finite checks and sequential tree addition even under cancellation;0/1/32/128/129rows must agree with the original. Preserve actual original coercions/errors and to_dict/fingerprint behavior demonstrated by pre-implementation observations. Canonical identity uses compact sorted-key JSON, ensure_ascii=false and Python-compatible finite float spelling; do not reuse M2's different spaced/ASCII serializer blindly.

Term/query encodings preserve original call order and dtype. Original query terms limit128; source-field terms limit4096; vocabulary blocks4096. Never materialize a complete vocabulary-by-query similarity matrix. Preserve full projection field order, unique term/body semantics, explicit missing-channel zeros and stable pool-relative ranks. Feature names/order come from the frozen original constants, including contextual/source-view extensions; evidence/feature versions1–3 remain supported. Fixed F32 absolute1e-6+relative1e-6 and F64 absolute1e-12+relative1e-12 bounds do not permit any change in threshold decisions, final ordered owners/evidence or ties. Dtype promotion, scalar/vector/matrix BLAS dispatch, axis reductions, quartiles and weighted one-row dot order must be explicit and validated before integration.

The original installed English algorithm is generated by Snowball3.0.1. Use official native Rust generation pinned to Snowball commit e4b3efb449ccb994d39230eb6e8440d267471f4a (annotated tagv3.0.1), retaining its BSD-3-Clause license and source/generation hashes. No compiler, Python runtime or downloads at application runtime. Preserve Unicode/lone-surrogate behavior by actual differential tests; if an ASCII-only grammar needs a lossless UTF-8 bridge, document its invariant and test collisions and restoration. Stem reuse retains at most32768entries, bypasses words longer than128codepoints, returns independent outputs, binds to provider ownership and shares no mutable word buffer between threads. Existing model term-cache8MiB/8192entries is unchanged unless a measured new workload demonstrates a necessary fix.

Candidate/description/evidence identity and hashes must match before embedding/ranking; reuse M4b's source-evidence invariant. A unique exact result bypasses optional numeric work and expansion. Expansion must return nonempty text. Evidence versions preserve original complete-owner versus retrieved-region choices. Stable ties preserve proposal order after exact priority and model score. Traces deep-copy observed features/signals/order, support opt-in query export, validate replayed scores/permutations/hashes and explain actual leaf paths/margins, without claiming causal attribution.

Registered native and piece forests remain exactly the original16/8-forest means (2560/1280trees). Their original fingerprints are6b563fed14ed276e1b310beba84006078ef65ab5d7d3cb5622d759f6a671e3a0 and62846d51f58e5da1cf27ad444073d14341bdc6368f8552a7bb1c30e8d6e7d9b9. New end-to-end feature composition may use an accepted static model; do not rerun unchanged model catalogs or training.
