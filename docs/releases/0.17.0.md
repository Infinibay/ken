# Ken 0.17.0

Ken now exposes KQL2 source queries, reusable source contracts, code investigation
tools, and English task-oriented skills through its CLI and MCP integration.

- KQL2 supports source selectors, BODY patterns, value relationships, reusable
  patterns, and an exploration backend for syntax queries. Acquisition budgets,
  selective graph access, persistent caches, and local hazard preparation reduce
  unnecessary work. Authoring diagnostics distinguish unsupported syntax,
  uncorrelated captures, incomplete coverage, and budget exhaustion.
- Source contracts support reviewed positive/negative examples, saved checks,
  before/after comparisons, and opt-in automation. Inspection tools connect
  ownership, callers, consumers, and existing implementations.
- Responsibility search combines documentation and source observations while
  retaining assumptions; heuristic scores are not calibrated probabilities.
- Findings can retain their rationale, evidence and dependencies. Recall checks
  recorded inputs before reusing a conclusion. Persistent reasoning operates over
  explicitly supplied premises and preserves conditional results.
- `ken install` distributes eight English skills, including complete KQL2
  examples and counterexamples, and supports Codex and DeepSeek Harness.

The distributed engines and resources live in `src/ken`. Local linguistic
experiments, Wikipedia data, generated visualizations and per-project assistant
installations are excluded from this release. The code-reasoning experiment
proposed after this release is not a shipped capability.

Known limits remain explicit: MCP `ken_find` uses the indexed KQL2 backend;
exploration is available through `ken kql2`. Text search currently does not apply
the structural `path` filter. Some unknown candidates still lack a detailed
per-candidate explanation. Structural findings do not establish runtime bugs
without the corresponding contract and behavioral evidence.

Validation: 14,454 tests passed and 10 expected failures, full package type
checking passed (284 source files), and the built wheel passed an isolated
installation and CLI smoke test outside the checkout. Wheel and source archive
contents were checked for local experiment and assistant-configuration files.
